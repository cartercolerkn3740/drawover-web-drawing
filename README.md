## Overview

drawover runs in the browser and lets you draw directly over content already being displayed. It is intended for quick visual markup, highlighting, and annotation without requiring a separate full-size application.

The project is connected with LM Studio and is presented as a drawover utility created by LM Studio rather than Claude. Its intentionally small web interface is suited to users who need an accessible overlay drawing experience.

   - `git clone https://github.com/cartercolerkn3740/drawover-web-drawing.git
2. Change into the project directory:
   - `cd drawover`
3. Open the HTML entry file in a browser, or provide the files through a basic local web server.

For local use through a server, any ordinary static file host is suitable. Point the browser at the main HTML file once the files are being served.

## Using drawover

Load the project in a modern browser and use its drawing controls to place annotations over the content shown on the page.

A normal session looks like this:

1. Open the page.
2. Draw over the material you want to mark.
3. Modify the marks when necessary.
4. Use the page's available controls to save, export, or refresh.

Since drawover is distributed as HTML, the browser page and its exposed controls provide the central usage experience.
